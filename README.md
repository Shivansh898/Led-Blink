# LED Blink 💡

A beginner-friendly Raspberry Pi project that demonstrates how to control an LED using Python and GPIO pins. The LED repeatedly turns on and off, helping users learn the fundamentals of electronics, circuits, and hardware programming.

## Features

- Control an LED using Raspberry Pi GPIO
- Written in Python
- Adjustable blink speed and timing
- Great introduction to physical computing

## Hardware Used

- Raspberry Pi
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

## Wiring

Connect:
- LED Anode (+) → GPIO Pin
- LED Cathode (-) → Resistor → GND

## Software

The project uses Python and the GPIO library to switch the LED on and off with a delay between each state.

## How It Works

1. The Raspberry Pi initializes the GPIO pin as an output.
2. The LED turns on.
3. The program waits for a short delay.
4. The LED turns off.
5. The process repeats continuously.
